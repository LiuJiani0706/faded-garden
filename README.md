# 失色花园 · Faded Garden

一个以「让花园重新拥有颜色」为线索的轻量倒水解谜游戏。点击瓶子整理色彩，每完成一种颜色，就点亮一朵花。

**[在线试玩](https://live-lialab-d6gxgtcsud40c9392-1330265879.tcloudbaseapp.com/)** · [v1.0.0 封存分支](https://github.com/LiuJiani0706/faded-garden/tree/archive/v1.0.0)

> 试玩部署在腾讯云 CloudBase。默认测试域名可能出现平台访问提示、限频或到期限制；不是永久服务承诺。

## 玩法与内容

- 固定 3×3 九瓶布局：先点源瓶，再点目标瓶；只能倒入空瓶或顶部同色且未满的瓶子。
- 60 个关卡：从二色逐步增加至七色，舒缓与挑战交替，以混色程度作为设计参考，不保证每关的实际难度严格递增。
- 三章短故事：唤醒温室、雾中的溪谷、花园的心脏。
- 花朵恢复色彩、瓶子完成标记、倒入弹动、错误反馈与通关庆祝。
- 支持提示、撤销、重开与自由选关；可手动开启音效，兼容设备提供轻微震动。
- 不包含排行榜、金币经济或可拖动的建筑经营场景。

## 本地运行

需要 Python 3；无前端依赖安装或构建步骤。

```sh
git clone https://github.com/LiuJiani0706/faded-garden.git
cd faded-garden
python3 -m http.server 5187 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:5187/ 。如果端口被占用，更换端口并打开对应地址。本地服务需保持运行；localhost 链接只适用于当前电脑。

## 进度与备份

自动保存在当前浏览器：当前关卡、瓶子状态、撤销历史、倒水次数及已完成关卡。同一浏览器、同一网址再次打开可恢复。

在「花园手记」中导出 JSON 存档，换设备或换域名后可导入。没有账号体系或云端同步：清除网站数据、使用无痕模式、换浏览器/端口/域名时，不能依赖自动恢复。建议定期导出。存档只留在本机，不上传至游戏服务器。

## 技术与目录

原生 HTML、CSS、JavaScript；规则、关卡和求解器与页面逻辑分离。提示搜索分片执行，搜索到上限时允许撤销或重来，不把未找到解法误判为无解。

```text
dist/index.html          页面与样式
dist/core.js             游戏规则、提示求解器与关卡数据
dist/app.js              交互、故事、动画及本地存档
levels.json              60 关数据与已验证解法
test.cjs                 无依赖的 Node.js 检查
.github/workflows/       GitHub Actions 测试
```

## 验证

需要 Node.js 22 或更新版本，运行：

```sh
node test.cjs
```

覆盖 60 关解法回放、模拟交互通关、通关记录、动作锁定、撤销，以及新会话恢复。模拟 DOM 检查不等于真实手机浏览器的视觉、音效与触感验收；关卡解法也不代表最短步数证明。

## 项目说明

这是一次借助 AI 辅助开发，将倒水规则、关卡验证、互动反馈和轻量叙事组合成可试玩作品的实践。v1.0.0 保留为独立封存版本，后续大花园经营方案不计入当前已完成功能。
