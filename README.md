# 失色花园 · v1.0.0

封存版：原生 HTML/CSS/JavaScript 倒水解谜，60 关，三章故事，修复花朵反馈。无排行榜、无大花园经营场景。

## 运行

运行 `python3 -m http.server 5173 --directory dist`，打开 http://localhost:5173 。不需要 npm 安装。测试：`node test.cjs`。

## 存档

自动记录当前关卡、瓶子状态、撤销历史、完成关卡及操作数。同一浏览器、同一网址再次打开可恢复。无账号或云端同步；清除网站数据、无痕模式、换设备/域名不能自动恢复。可导出 JSON 存档并在另一设备导入。更新关卡使用独立存档命名空间，不覆盖旧试玩版存档。

## 难度

固定九瓶布局，颜色从二色逐步升至七色，每对关卡按舒缓/挑战交替，以混色边数为难度代理，不宣称最短解或绝对难度。60 关均有经过回放验证的解法。前期空瓶较多，适合教学。

## 验证与边界

测试覆盖全部关卡解法、完整交互通关、记录写入、动画锁定、撤销。未完成本轮真实手机浏览器验收。花园修复表现使用符号花朵；大型可拖动花园仍为独立的未来方案。

发布前不包含用户实际存档、账号、Sites 凭据或个人资料。
